# RAG流式输出

网页提问改用POST /api/rag/ask/stream（SSE），原POST /api/rag/ask JSON接口保留。仅修改独立RAG，未改Agent。

顺序：检索状态→来源片段→模型增量文本→最终引用校验→完成结果。前端在生成时用textContent展示未校验草稿，状态明确标记引用待核对；完成后用既有安全展示器呈现格式与可点击引用，再启用复制/反馈。连接中断、服务端错误、缺少完成事件或引用失败均清除草稿，不当成有效答案，也不自动重试。

阿里云请求stream=true、stream_options.include_usage=true；读取实际UTF-8 SSE增量，要求finish_reason=stop和[DONE]完整结束，保留usage与耗时轨迹。输出超长/截断/超时均停止，响应连接在finally关闭。客户端终止读取时生成器关闭并记录cancelled；这是有限连接清理，不声称任意网络中断都即时取消上游计费。

demo仍是离线原文摘录，直接返回完成事件，不伪造模型逐字输出。重排仍在生成前完成，流式只改善生成阶段的等待体验，不保证总耗时缩短。
