# 流式即时排版

用户反馈：生成时夹杂格式符号，结束后才排版。原实现将delta以纯文本展示，done后才调用richText。

现改为每70ms合并增量，生成期间调用既有安全Markdown展示器。展示副本临时闭合未完加粗/行内代码、隐藏半截引用ID及孤立格式前缀，完整引用统一格式后显示来源按钮。代码围栏内部保持原文；仍通过textContent/DOM节点构造，不把模型文本作为HTML执行。

后端流、调用次数、引用校验与完整答案不变。done后使用真实完整回答重新排版并开启复制/反馈；error/断流会取消待渲染计时器并清除草稿，避免延迟回调覆盖错误界面。动态结构可能随新文本微调，不能提前获知整篇文章最终结构；本版不是完整CommonMark解析器，不新增表格/数学公式全语法支持。

测试：Node tests/test_stream_format.js通过，覆盖分包加粗及单星号、代码/引用前缀、围栏原文、最小DOM标题/列表/加粗结构和HTML安全；tests/test_stream_client.js及app.js语法检查通过。pytest tests/test_frontend_assets.py 1项通过，确认脚本版本及资产可加载。本次没有新增外部模型调用，也未新增浏览器点击验收，不将最小DOM测试当真实浏览器验证。

当前仅修改RAG静态文件，服务不需重启；页面脚本缓存版本已升级ui.js v3、app.js v4，用户Ctrl+F5刷新即可。未改Agent，未修改索引和业务数据。源码包更新；原交付范围6/8保持。
